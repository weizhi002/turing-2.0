图灵2.0 大模型情感智能评测范式

将情感大模型从“识别情绪”扩展到“理解、表达、调节、使用、社会适应与安全交互”的综合性测评。

EI-META = { P, U, E, R, G, S, A }

大模型情感智能综合性评测体系

每个维度都对应一组可落地的 AI 任务，并映射到人类情绪能力标准：感知、理解、表达、管理、决策、社会互动与负责任回应。

P

情感感知

识别表情、语音、文本与情境中的情绪信号。

类别 / 强度 / 维度 / 微表情
U

情绪理解

解释情绪原因、对象、需求与文化语境。

因果 / 混合 / 隐含 / 文化语境
E

情绪表达

生成恰当、真实、可理解的语言与多模态表达。

安慰 / 鼓励 / 语气 / 多模态一致
R

情绪调节

管理焦虑、重评冲突、转移注意并稳定互动。

认知重评 / 冲突降级 / 策略适配
G

情绪使用

把情绪作为注意、判断和行动决策的信息。

风险偏好 / 任务匹配 / 问题解决
S

社会适应

理解角色、关系、礼貌、文化规范与群体情绪。

礼貌面子 / 关系修复 / 群体情绪
A

安全交互

识别危机、保持边界并给出负责任回应。

危机回应 / 隐私保护 / 依赖风险

输入与任务

评测输入覆盖文本、语音、视觉、行为、生理信号与对话上下文。任务不再只问“是什么情绪”，还要问“为什么产生、如何表达、如何调节、如何用于决策”。

指标设计

基础层使用 WAF、F1、CCC、MAE 等客观指标；生成与交互层加入证据一致性、共情质量、策略适配、社会规范和安全边界评分。

人类能力映射

7 个维度分别对应情绪知觉、情绪知识与推理、情绪表达与沟通、情绪管理、情绪促进思维、社会情绪能力和心理急救式安全回应。

从公开挑战赛到综合测评

MER / ABAW / MuSe 提供底座指标

MER-SEMI、MER-FG、MER-DES、MER-Prefer、MER-PS 侧重多模态识别、开放词表、描述式理解、偏好判断与生理信号；ABAW 与 MuSe 提供 VA、表情、AU、复合表情、压力和真实场景连续情绪指标。

图灵2.0 负责能力综合化

平台将挑战赛指标映射到 P/U/E/R/G/S/A 七类能力，形成可比较、可复现、可解释的综合分数，并支持模型提交、人工复核、偏好评分与安全审查。

提交结果所需信息

模型与版本

模型名称、参数规模、模态输入、推理配置和发布日期。

评测维度

明确提交 P/U/E/R/G/S/A 中哪些维度，以及对应任务集。

数据与协议

列出使用的数据集、划分方式、许可证和是否包含私有测试集。

指标与证据

提供客观指标、人工评分规则、失败案例和可复现实验脚本。
