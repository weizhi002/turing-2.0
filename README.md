# 图灵2.0 (Turing 2.0)

大模型多模态情感与情绪智能能力基准测试与交互平台。

**Turing 2.0** 是一个开放、透明、可复现的多模态情感智能评估与交互平台，聚焦 MER、ABAW、MuSe、生理信号、微表情、情绪对话与 LLM 情绪智能评测。

## 网站结构

- `index.html`：项目首页
- `datasets.html`：多模态情感数据集库，详情卡面包含来源、链接、发布时间、发布机构、模态、任务、采集标注、处理流程、榜单、引用与使用限制等维护字段
- `methodology.html`：测评框架与理论基础
- `leaderboard.html`：情感能力榜单页面
- `interaction.html`：在线多模态情感交互 Demo
- `NOTICE-NONCOMMERCIAL.md`：非商用版权声明
