# 图灵2.0 (Turing 2.0)

大模型多模态情感与情绪能力基准测试与交互平台

**Turing 2.0** 是一个开放、透明、可复现的多模态情感智能评估与交互平台。

## 网站结构
- `index.html` — 项目首页
- `datasets.html` — 多模态情感数据集库
- `methodology.html` — 原创测评范式与框架
- `leaderboard.html` — 情感能力基准榜单
- `interaction.html` — 在线多模态情感交互 Demo（支持自定义人设）
